# H-4 Some Disassembly Required

## x.) Tiivistelmät

- strace paljastaa ohjelman ja käyttöjärjestelmän välisen keskustelun (järjestelmäkutsut ja vastaanotetut signaalit)
- esimerkiksi; tiedoston avaaminen ja lukeminen, verkonkäyttö
- ltrace paljastaa saman mutta kirjastokutsuille
- esimerkiksi; tulostus- ja merkkijonojen funktiot
- ghidra on ilmainen reverse engineering työkalu
- käytetään kun ohjelman lähdekoodia ei ole saatavilla
- voidaan tutkia binääritiedostoja

Tämä Kali Linuxille nopea ```sudo apt-get install ghidra```
